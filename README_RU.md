# IPChanger

Утилита для быстрого переключения статических IP-адресов, DHCP и DNS на сетевых адаптерах Windows.

## Возможности

- Просмотр текущих настроек сетевых интерфейсов
- Установка статического IP, маски, шлюза и DNS
- Переключение на DHCP
- Сохранение пресетов для каждого адаптера
- Поддержка русского, английского, сербского и узбекского языков
- Единый экземпляр приложения

## Меню в трее

![Меню в трее](traymenu.png)

Контекстное меню иконки в трее предоставляет следующие опции для каждого интерфейса:

- **Пресеты** — сохранённые конфигурации. Каждый пресет отображает IP, маску, шлюз и DNS в подсказке.
  - **Применить** — применить настройки пресета
  - **Редактировать** — изменить пресет
  - **Удалить** — удалить пресет
  - **Нет сохранённых пресетов** — отображается, когда для интерфейса нет пресетов
- **Добавить пресет** — создать новый пресет
- **Сохранить текущие настройки как пресет** — сохранить активные настройки интерфейса
- **Установить DHCP** — переключить интерфейс на автоматическое получение IP и DNS
- **Свойства** — открыть диалог свойств TCP/IPv4 Windows для интерфейса

Глобальные пункты меню (внизу):

- **ipconfig /all** — отобразить полную конфигурацию IP в окне
- **Сетевые подключения** — открыть папку сетевых подключений Windows
- **Язык** — выбрать язык интерфейса (русский, английский, сербский, узбекский)
- **О программе** — показать диалог с информацией о версии
- **Выход** — закрыть приложение

## Требования

- Windows 10/11
- .NET 9.0 Runtime
- Права администратора

## Сборка

```bash
dotnet build --configuration Release
```

## Публикация (самостоятельный exe)

```bash
dotnet publish --configuration Release
```

Собирает 64-битное приложение для Windows с встроенными переводами.

## Сборка MSI-инсталлятора

```bash
dotnet build --configuration Release -t:Publish
```

Автоматически собирает приложение и MSI-инсталлятор (через WiX). Инсталлятор отображает текст лицензии на этапе установки.

## Настройки

Профили сохраняются в `%LOCALAPPDATA%\IPChanger\profiles\*.json`. Настройки приложения — в `%LOCALAPPDATA%\IPChanger\settings.json`.

Переводы хранятся в `%LOCALAPPDATA%\IPChanger\Translations\*.json` и также встраиваются в каталог установки.
